## 3. COLREGs 가 엇갈린 이유 (Woerner 세부, 시드 44)

| 역할 | OFF 점수 / T(방향) / A(뚜렷함) | 통신 점수 / T / A |
|---|---|---|
| 양보(교차) | 52.1 / 79.6 / 91.3 | 46.3 / 71.7 / 89.3 |
| 정면 | 16.0 / 76.8 / 91.3 | 13.0 / 70.9 / 88.5 |

- T = 주로 좌현으로 돌면 0.5(Woerner Alg., `colregs_woerner.py`) → 시드 44 통신 배는 **좌현 회피가 더 많음**. A(변침이 뚜렷한가)도 약간 낮음 = 작게 꺾음
- 56–300 m '양보 우현' 43.3 → 35.0 %, '둘 다 유지' 10.2 → 19.3 % → 멀리서 침로를 덜 바꾸고 작게 조정
- 시드 43 은 T 가 두 팔 비슷(양보 79.7 / 77.4) → 시드마다 다른 회피 습관
- 해석: 현 보상은 안전·효율을 강하게, COLREGs 방향은 약하게(판정기 −20/건) 보상 → 통신 배는 안전·효율 쪽으로 배움. 목표 a(COLREGs)는 아직 보상이 받쳐 주지 못함(가설)
