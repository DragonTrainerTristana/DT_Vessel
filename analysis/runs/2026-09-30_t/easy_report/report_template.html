3. 서로 역할을 알면 COLREGs 준수가 좋아져야 하는데, 왜 안 되나?

한 줄 답: "알면 좋아진다"는 지키는 게 이득일 때만 참임. 지금은 ① 지켜도 점수가 없고 ② 둘 다 피하는 게 더 이득이고 ③ 점수 매기는 방식이 '서로 맞춘 것'을 못 봄.

비유: 교차로의 두 차에 무전기를 줬음. 그런데 점수는 "안 부딪혔나"로만 주고 "양보 순서를 지켰나"엔 안 줌 → 둘 다 미리 브레이크 밟고 비켜 감. 단속 카메라는 교차로 안 10 m 에서 차 한 대의 핸들만 찍음 → 멀리서 미리 맞춰 비켜 간 건 안 보임.

4. 앞으로 할 일

순서가 중요함: 학습 없이 확인 → 지표 먼저 → 보상은 학습 전에 검사 → 통과한 것 1개만 학습. 전부 저자 승인 필요, OFF 에도 똑같이 적용.

무엇왜시간 · 학습
1기존 t_ 체크포인트 다시 평가: 긴 에피소드 끝까지 마감(--drain), 통신 끊기 실험(msgzero·shuffle), 역할별·명령 타각별 준수율 같이 출력 원인 ⑤를 t_ 에서 직접 확인. 안전 이득이 측정 착시가 아닌지 확인Windows 몇 시간
학습 없음
2'서로 맞춤'을 재는 짝 지표 만들기: 조우 시작 때 역할 고정 → 양보선이 피해서 풀렸나 · 유지선이 버텼나 · 안전 통과했나 (누가 움직였는지 기록) 지금 지표로는 통신이 잘하는 걸 못 봄(원인 ③④). 규칙 배 순서(규칙 지키는 배가 1등)로 지표가 맞는지 먼저 검사CPU 몇 시간
학습 없음
3보상 후보를 학습 전에 검사: ① 레이더 안 유지선 침로 유지 점수 되살림 ② '풀림'은 양보선이 피했을 때만 인정. 새 규칙 배 "양보선만 일찍 피하고 유지선은 버팀"을 추가 원인 ①②. 이 규칙 배가 1등이 되는 보상만 통과 → 보상이 '역할 지키기'를 원하게 됨CPU 몇 시간
학습 없음
4통과한 보상 1개만 바꿔 배치 1회 (OFF · OFF 재분기 · 통신 a6). 판정은 2번의 짝 지표 + 기존 지표 같이 한 번에 하나만 바꿔야 무엇이 효과인지 앎배치 1회(약 하루)
학습
5그래도 통신 우위가 안 나오면 "준수 우월" 대신 "안전 우월"(충돌↓·통과거리↑)로 주장 정리 결과에 맞춰 지표를 바꾸는 게 아니라, 결과 전에 미리 정해 둠저자 결정

하지 말 것

  • 300 m 밖 준수에 + 점수 주기 — g_ 배치에서 배들이 과하게 돌기만 했음(양보 변침 39° → 78–86°)
  • OFF 가 못 보는 거리에서 벌점 주기 — v_ 배치에서 OFF 만 약해졌음(조작 시비)
  • 코덱 차원 늘리기 · 역할 선언 늘리기 — a2 ≥ a6, a8 효과 없음
  • t_ 결과를 새 지표로 다시 판정해서 결론 바꾸기 — 새 지표는 옆에 적기만 함

정직한 기대치 (주관 추정)

  • 보상을 고치면 OFF·통신 둘 다 COLREGs 점수가 오를 것. 다만 56 m 안 점수에서 통신이 OFF 를 이기는 폭은 거의 0 일 것
  • 통신이 이길 수 있는 곳은 짝 지표(양보선이 멀리서 피하고 유지선은 버티며 안전 통과). 규칙 배로는 약 3배였지만, 학습 정책에서 될 확률은 반반 이하로 봄
  • 학습 전 검사(3번)에서 어떤 보상도 "양보선만 피하는 규칙 배"를 1등으로 못 만들면, 이 환경에선 준수 우월 주장을 내려놓는 게 정직함
직관에 대한 답: "서로 알면 준수가 좋아진다"는 맞는 말이지만 조건이 있음 — 지키는 게 이득이어야 함. 지금 보상에서는 알아도 지킬 이득이 없어서, 통신 정보가 '둘 다 일찍 피하기'로 쓰이고 있음.
