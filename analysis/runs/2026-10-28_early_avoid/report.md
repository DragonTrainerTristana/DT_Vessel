## 0. 결론

- 미리 피한 배에게 '상'을 직접 주지 않음. 대신 **'곧 받을 벌을 미리 보여 주는' 위험 예고 보상(PBRS, 퍼텐셜 기반 보상 변형)** 을 0–300 m 하나의 연속 함수로 새로 둠
- 이유: 최적 행동을 바꾸지 않음(Ng 1999) → 통신을 이기게 만드는 조작이 아님 · 쌓아 먹기·우회·시간초과 유인 없음 · 미리 피한 효과가 즉시 신호로 옴(학습 연결 문제 해결)
- 기존 원거리 PBRS(#8 `farfield_coef`)는 56 m 경계에서 끊겨 '가까이 들어오면 상'이 생기는 결함 → 그대로 쓰지 않음

## 4. G 설계 세부 (제안 — 숫자는 결과 전 고정)

- g(dcpa) = clamp((48 − dcpa)/24, 0, 1) — 보상 위험 비용과 같은 DCPA 게이트(48 m)
- h(tcpa) = 접근 중(tcpa ≥ 0)일 때 1 − clamp(tcpa/T, 0, 1), T = 300 m 도달 시간 상한(예: 120 s). 멀수록 작게
- 56 m 경계에서 끊기지 않음(sit 곱·띠 경계 없음) · 상대가 지나가면(tcpa < 0) 0 으로 부드럽게
- F = γΦ(s′) − Φ(s), γ = 0.99(학습기와 같음) · 끝난 배(충돌·도착·시간초과)·재출현 첫 결정은 F = 0(충돌 순간 '+|Φ|' 막음)
- c: 위험한 조우 하나를 그냥 지나갈 때 56 m 안에서 받는 비용 합과 같은 크기 → 이미 있는 평가 로그에서 측정해 정하고 고정
- 토글 기본 0(비트동일), 스냅샷 키 추가, 순위 관문 v5 에 같이 넣어 '잘 피하는 배가 더 높은 점수' 확인
- 위험
  - OFF 는 Φ 의 원인(56 m 밖)을 못 봄 → 조우마다 합 0 이지만 잡음 → OFF 학습이 느려질 수 있음 → **PBRS 있/없 OFF trunk 비교로 확인**(OFF 가 나빠지면 통신 이득을 주장 못 함)
  - 다중 에이전트·부분 관측에서는 '최적 행동 불변' 보장이 약해짐 → 결과로 확인
  - 기존 earlyAvoid(9-b, 56 m 안 DCPA 증가에만 +)는 지그재그로 쌓아 먹을 여지 → 크기는 작음(조우당 +3~6), 보고만
