0. 묘책 한 줄

  • 1단계 = 이미 검증된 OFF trunk(qd_ 보상, 시드 43·44 처방 기준 3/3) 를 그대로 재사용 → 2단계 = 두 팔 모두 '원거리 COLREGs 규칙 벌점(300 m)' 을 켠 같은 보상으로 OFF·통신 갈래
  • 이미 돌린 갈래(벌점 없음)는 버리지 않고 비교 축으로 씀 → {OFF, 통신} × {원거리 규칙 벌점 없음, 있음} 2×2

1. 왜 가장 안전한가

  1. 가장 위험한 부분(OFF 가 처음부터 배우기)을 다시 안 함 — 이미 성공한 trunk(시드 43·44)를 그대로 씀. 새 시드(45–47) trunk 도 검증된 qd_ 방법 그대로
  2. 2단계에서 더하는 건 '하면 안 되는 행동'(양보·정면 배 좌현, 유지 배 침로 변경)의 벌점뿐 → 이미 피할 줄 아는 배가 방향만 고치면 됨. 처음부터 배우는 것보다 훨씬 쉬움
  3. 버리는 계산이 없음 — 2단계가 잘 안 되면 같은 trunk 로 대안 A(벌점 없는 갈래, 이미 2 시드 있음)를 그대로 이어감
  4. 짧음 — 시드 43·44 는 trunk 가 있어 2단계 갈래만(약 3.5 h). 새 시드 trunk 와 동시에 돌림
  5. 공정성 유지 — 각 단계에서 두 팔 보상 완전히 같음. 같은 trunk 짝. 메시지 입력만 다름

2. 왜 저자 논리대로인가

목표 2단계가 주는 것
a) COLREGs 300 m 안 조우 전체에서 규칙 방향이 보상됨 → 멀리 보는 통신 배만 '일찍 우현'으로 지킬 수 있음 (지금 엇갈림의 원인 = 56–300 m 좌현이 공짜였던 것)
b) DCPA 넓음 거리 관련 보상은 두 팔 같음(56 m 위험 비용 그대로)
c) 매끄러움 이미 2/2 시드에서 나옴. 규칙 벌점은 '작게 일찍 우현'을 막지 않음
d) 학습 흉내 없음, 순수 PPO 두 단계
곡선 우상향 모든 체크포인트(trunk·갈래)를 2단계 보상으로 같은 장면 평가 → x 축 전체가 같은 보상 정의. 갈래에서 규칙을 배우며 오름

3. 논문 서술 (리뷰어가 자연스럽게 받아들이는 형태)

  • "커리큘럼: 1단계에서 통신 없이 항해·근거리 충돌회피를 배우고(공유 사전학습), 2단계에서 COLREGs 규칙을 조우 범위 전체로 넓혀 통신 유무만 다르게 이어 학습"
  • 왜 처음부터 안 하나 → 근거 있음: 관측 못 하는 거리의 보상 항을 처음부터 넣으면 학습이 무너짐(n_ 300 m 위험 비용 27.3 %, qe_ 예고 보상 0/3)
  • 2×2 결과가 보여 줄 이야기(가설): "통신은 보상이 요구하는 것을 더 잘하게 해 줌 — 규칙 벌점이 없으면 효율적인(좌현 포함) 회피, 있으면 일찍 우현의 규칙 회피." 통신이 정보 증폭기라는 깔끔한 메시지
