## 1. 통신 버그 발견

### 문제 현상
- `USE_COMMUNICATION = True` (Phase 2)로 학습 시 오히려 성능 저하
- 목적지까지 못 가는 현상 발생

### 원인 분석

#### 버그 1: comm_partners를 forward에 전달 안 함

**main.py 기존 코드:**
```python
# comm_partners 계산은 함
comm_partners = {}
for agent_id in agent_id_list:
    partners = get_comm_partners(...)
    comm_partners[agent_id] = partners

# 근데 forward에 안 넘김!
values, actions, logprobs, means, _ = policy.forward(
    states_tensor, goals_tensor, self_states_tensor, colregs_tensor
)  # comm_partners 없음!
```

#### 버그 2: 환경 간 메시지 섞임

모든 환경의 에이전트를 하나의 배치로 합쳐서 처리:
```python
for env_data in env_data_list:
    all_states.extend(env_data['batch_states'])  # 전부 합침
```

결과: **환경 0의 에이전트가 환경 1의 에이전트 메시지를 받음** (의미 없는 노이즈)

#### 버그 3: evaluate_actions에서도 같은 문제

PPO 업데이트 시 others_msg가 forward와 다르게 계산됨

## 3. 통신 흐름 (수정 후)

### 메시지 생성 및 교환

```
나: obs → MessageActor → 내 msg ──────────┐
                                          ↓
이웃A: obs → MessageActor → A의 msg ──→ 합산 → others_msg
이웃B: obs → MessageActor → B의 msg ──┘      ↓
                                          나의 ControlActor
                                              ↓
                                           action
```

### 추론 vs 학습 일치

```
추론 시:
  forward(comm_partners) → others_msg 생성 → action 결정
                              ↓
                          경험에 저장
                              ↓
학습 시:
  evaluate_actions(저장된 others_msg) → logprob 계산
```

**forward와 evaluate_actions에서 동일한 others_msg 사용** → 일치함

## 4. COLREGs Clear 조건 추가

### 문제

서로 오른쪽(starboard side)에 있으면 이미 안전하게 지나가는 중인데, 계속 회피하려고 함

### 기존 Clear 조건

```csharp
// 1. 상대가 뒤에 있으면 Clear
if (Mathf.Abs(bearingAngle) > 100f) return None;

// 2. 서로 왼쪽에 있으면 Clear (port-to-port)
if (bearingAngle < -10f && otherBearingAngle < -10f) return None;

// 3. TCPA < 0 이면 Clear (이미 지나침)
if (rawTCPA < 0f) return None;
```

### 추가된 Clear 조건

**COLREGsHandler.cs:**
```csharp
// ★ Clear 조건 3: Starboard-to-starboard passing 체크 ★
// 서로 오른쪽(starboard)에 있으면 이미 안전하게 지나가는 중 → 회피 불필요
if (bearingAngle > 10f && otherBearingAngle > 10f)
{
    return CollisionSituation.None;  // Starboard-to-starboard로 안전하게 지나가는 중
}
```

### Clear 조건 요약 (4개)

| 조건 | 의미 |
|------|------|
| `\|bearing\| > 100°` | 상대가 내 뒤에 있음 |
| `bearing < -10° && otherBearing < -10°` | 서로 왼쪽 (port-to-port) |
| `bearing > 10° && otherBearing > 10°` | 서로 오른쪽 (starboard-to-starboard) ← NEW |
| `TCPA < 0` | 이미 최근접점 지남 |
