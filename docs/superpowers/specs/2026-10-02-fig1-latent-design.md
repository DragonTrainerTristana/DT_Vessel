## 2. 설계 (고정)

| 부분 | 내용 |
|---|---|
| 행동 | `VESSEL_ACTION_MODE=course`: a0 = 목표 방위 기준 침로 변경량/120°, a1 = 목표 속도. env 조타 제어기(오차 10° = 전타)가 타 명령. 기본 'rudder' = 비트동일(Mac 확인: 120스텝 텐서 481개 일치) |
| OFF 입력 | 레이더 + 56 m 안 상대 필드(arpa: 참값 상태·역할, 의도 없음) |
| 통신 입력 | OFF 입력 + 300 m 안 배의 메시지. 메시지 = 고정 코덱 z(6, 8비트 = 48비트) |
| 메시지 내용(보내는 배) | [고정 레이더 인코더 복사본 출력 30 + 핵심 16] = 46 → 6. 핵심 16 = 운동 6(sin·cos 침로, 속력, 선회율, 명령 타각, 명령 속력) · 의도 2(계획 침로 변경량/120, 계획 속력) · 역할 선언 4 · 선언 대상 위치 2 · 목표 방향 2 |
| 레이더 인코더 복사본 | trunk 끝 정책의 레이더 인코더를 복사해 동결(코덱 파일에 같이 저장). 자기 조종용 인코더는 계속 학습 |
| 코덱 | 46 → 6 오토인코더, 실제 상태(trunk 정책·선생님 rollout)로 학습 후 동결, SHA 고정. 손실 가중: 운동·의도 ×10, 역할·대상 ×4, 목표 ×1, 레이더 임베딩 ×0.1 |
| 받는 배 | 파트너 필드의 '보낸 배 값'을 코덱 복원값으로 채움(decode). 56 m 안은 센서 참값(OFF 와 같은 정보), 56–300 m 는 복원값. 의도 필드는 복원값만(센서로 못 봄) |
| 선생님 | OFF ← vo56 또는 vo56h150(§5 규칙), 통신 ← vo300i |
| 학습 | trunk: OFF 설정, 선생님 흉내(DAgger) → PPO. 갈래: off · comm6 · offb, 흉내 보조손실(팔별 선생님, 같은 감쇠 일정) |
| 보상 | v3 그대로(t_ 와 같음) |

## 4. 관문 (결과 전 고정)

1. 코덱 복원(holdout, k = 4·6·8·12 모두 측정): 의도 침로 오차 p90 ≤ 10°, 침로 오차 p90 ≤ 5°, 속력 오차 p90 ≤ 0.1 m/s,
   역할 선언 정확도 ≥ 95 %. k = 6 이 통과하면 6, 아니면 통과하는 가장 작은 k(8 → 12), 셋 다 안 되면 멈추고 보고
2. 흉내 관문(PPO 전 학생, 팔별 선생님): 시드마다 도착 ≥ 80 % · 충돌 ≤ 15 %, 3/5 이상 → 진행
3. trunk 관문 = t_ 규칙(마지막 4창 goal ≥ 30 % · oColl ≤ 5 %, 앞 3시드), G1 기록만

## 4-1. 구현 중 고정한 세부값 (2026-10-02, 결과 전)

- 파트너 수 K = 8 (trunk·갈래 모두). 선생님 vo300i 는 300 m 안 모든 배를 봄
- 흉내 보조손실 = −log π(선생님 행동), 같은 평가 경로. coef 1.0 → 0, 3,000,000 결정 동안 직선 감소(trunk 는 0 부터, 갈래는 분기점부터). 팔마다 자기 선생님(OFF·offb ← OFF 선생님, 통신 ← vo300i)
- DAgger(trunk 앞, ARPA 경로) = −log π 최소화(logstd 고정), 기존 3000 결정·β 일정 그대로
- 코덱은 시드마다 그 trunk 의 레이더 인코더로 만듦(수집 = trunk 체크포인트 + vo300i 함대). k 선택 = 관문 시드 전부가 통과하는 가장 작은 k(6 → 8 → 12), 없으면 멈춤
- 역할 선언 정확도 = 참 또는 복원 선언이 있는 표본에서 정확히 같은 비율('없음'이 대부분이라 단순 정확도는 부풀려짐)
- 공통 뿌리 = ARPA@56·메시지 없음 ON 모델(latent 0·코덱 없음·파트너 반경 ≤ 레이더 범위). 학습기 분기 검사·check_branch 가 OFF 짝으로 인정
