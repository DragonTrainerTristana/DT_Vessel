## 1. 수정 — `VESSEL_COLREGS_FAR_MODE=penalty` (기본 `full` = 5d95b5a 그대로)

- 원거리 채점 칸(`_uf`: 56 m 안 상황 없음 + 300 m 안 충돌위험 상대 + risk 게이트)만 **위반 벌점**으로 바꿈
  - 양보선(HeadOn·GiveWay·Overtaking): 좌현 변침(`_nr < -0.1`) −0.5
  - 유지선 Rule 17(a) 구간: 침로 변경(`|_nr| ≥ 0.1`) −0.5, 속도항은 음수 부분만(−0.5 / −1.0)
  - 가산 0: 우현 보너스·침로유지 보너스·17(b) 회피 보너스 없음
- 계수·riskw·게이트는 같은 식(`COLREGS_SIM_COEF × comp × (1+risk)`)
- 56 m 안 채점은 그대로. 관측·신경망·코덱 불변
- 근거
  - 가산이 없으므로 오래 돌아도, 위험 상황에 들어가도 이득이 없음(파밍 불가)
  - 통신 없는 배는 레이더 밖 역할을 못 보므로 "좌현 변침·침로 변경이 가끔 벌점" = 직진 쪽 약한 치우침. 우현 선회 유인(g_off 악화 원인)은 없음
- 모든 팔 동일, 분기점(9,043,968)부터. 학습기는 분기점에서만 trunk 와 달라도 허용, 크래시 재개는 일치 강제. sim 스냅샷 키 26번째

## 3. 사전등록 판정 (결과 전 고정)

- **최선 OFF** = {x_off, h_off, v_off} 가운데 시드 평균 vColl 이 가장 낮은 팔. 모든 지표에 이 한 팔을 씀
- **잡음 N(지표별)** = 시드별 |h_off − x_off| 의 최댓값 (같은 trunk·같은 보상 재학습 차이)
- **지표 3개** (eval 출력 줄 이름 그대로, 방향 고정)
  1. vColl ↓
  2. `[pair-detail] 통과최소거리 중앙` ↑
  3. `[조율/레이더 밖 56-300m] 보완(양보 우현+유지 유지)` ↑
- **지표별 통과** = 최선 OFF 와 시드별 짝 비교 3/3 승 **그리고** 평균차 > N. vColl 은 평균차 > 6 pp 도 필요. 소수 1자리 동률 = 승 아님
- **목표 달성** = v_a6 가 3개 모두 통과
- **보조**: h_a6 vs 최선 OFF 같은 규칙(옛 보상에서의 latent 효과)
- **판정 밖, 그대로 보고**: `[encounter-COLREGs/실제타각] C`(역할별 포함), 레이더 안 보완, headTravel·fuel·len, oColl·TO, 옛 규칙(평균차 > x_off 시드 범위) 판정
- **"latent 메시지 덕분" 문구**: v_a6 절제 `msgzero`·`shuffle` 둘 다 vColl 3/3 악화일 때만. 아니면 "통신 채널 이득, 메시지 내용 기여 미확인"
- **H1a**: v_a6 가 최선 OFF 보다 vColl 3/3 나쁘고 평균차 > N 이면 FAIL 로 보고
- 금지: 결과 본 뒤 반경·계수·방식·코덱 재튜닝, 시드 추가(다음 주기 사전등록으로만)

## 4. 한계 (결과 전 기록)

- 준수 지표 3번은 레이더 밖(통신만 정보를 주는 구간)임. 레이더 안 C 는 trunk 습관으로 고정돼 이번 개입으로 못 움직인다고 봄 — 결과 전 기록
- 잡음 N 은 시드당 재학습 1회(값 3개)라 작은 표본임
- a6 는 grounded latent(송신자 상태에 묶인 6차원·48 bit)이고, 스스로 배운(emergent) 통신이 아님. 6D→6D 라 압축 아님
- gym 전용(Unity 판정관 미러 없음)
- (사전 점검 추가, 결과 전) a6 도 원거리 채점 상대의 약 1/3(휴리스틱 32%, 평균 213 m)을 못 봄 — 파트너 4척 밖. a6 에 불리한 쪽(보수적)
- (사전 점검) 끝점 2 는 56 m 안에서 sit>0 로 들어온 쌍만 셈. 원거리에서 해소된 쌍은 빠짐 → 처치에 보수적. 팔별 쌍 조우 n·allMinSep 을 같이 적음
- (사전 점검) 벌점형은 원거리 양보 우현을 가산하지 않음 → §0 의 g_a6 보완 수치(우현 보너스 영향)는 이번 배치로 그대로 이어지지 않음. 우현 성분은 충돌코스 비용·좌현 벌점으로만 간접 유도
- (사전 점검) 끝점 3 은 56–300 m 전쌍 기준, 보상은 최고위험 원거리 1척만 채점 → 희석 가능
- (사전 점검) x_off s43·s45 는 크래시 재개 런(14.02M·12.06M, 워밍업 1200), s44 는 연속 → N 에 재개 흔들림 포함(보수적). h_off 가 최선 OFF 이면 N 도 정함(보수적)
- (사전 점검) v_off 는 못 보는 벌점을 받음 → v_a6 vs v_off 차이는 통신 효과로 해석하지 않음
